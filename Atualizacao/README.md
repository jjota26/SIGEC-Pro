# Pasta de Pacotes de Atualização de Software - SIGEC-Pro

Esta pasta é destinada a armazenar pacotes de atualização (.json) contendo **exclusivamente definições e versões de software** do sistema SIGEC-Pro.

- NUNCA contém dados de registo de clientes, contactos ou projetos.
- Ao clicar no botão **"Verificar Pasta"** ou **"Importar Ficheiro de Atualização"**, o programa consulta a pasta **Atualização** no servidor GitHub e identifica a versão mais recente.
