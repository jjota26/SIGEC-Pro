# Pasta de Cópias de Segurança (Backup) - SIGEC-Pro

Esta pasta é destinada a armazenar as cópias de segurança (backups) contendo **exclusivamente os dados de registo** do sistema SIGEC-Pro (Clientes, Contactos, Projetos e Interações).

- Os backups gerados no sistema são guardados aqui e no repositório GitHub (`Backup/Backup_SIGEC-Pro_Data_Hora.json`).
- Ao clicar no botão **"Restaurar Backup"**, o programa procura automaticamente na pasta **Backup** do servidor GitHub a versão mais recente.
